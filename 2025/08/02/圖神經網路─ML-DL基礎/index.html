圖神經網路─ML/DL基礎

Created2025-08-02|Updated2025-08-02|學習筆記
|Post Views:

筆記內容來自 CS224W: Machine Learning with Graphs Stanford / Fall 2021

機器學習可以看作是一個最佳化問題

  • 目標函數： $\mathop{min}\limits_{\theta} L(y, f( x))$
    • 最小化 loss 值，例如：L2 loss (MSE), $L(y,f(x))=||y-f(x)||_2$
    • 其中的 $\theta$ 是要去訓練的模型參數

損失函數 (Loss functions)

  • 常見的 loss function:
    • Cross entropy: $L(y,f(x))=-\sum_{i=1}^n y_i \log f(x_i)$，$Y_i$ 為 one-hot encoding，$f(x_i)$ 是模型預測的機率值
    • L1 loss (MAE): $L(y,f(x))=\sum_{i=1}^n |y_i-f(x_i)|$

怎麼去優化目標函數？

  • 方法一：梯度下降 (Gradient Descent)

    1. 梯度向量 $
      \nabla_\theta L = \left(\frac{\partial L}{\partial \theta_1}, \frac{\partial L}{\partial \theta_2}, \cdots, \frac{\partial L}{\partial \theta_n}\right)
      $

      對損失函數 (L) 做偏微分，得到模型參數的更新方向

    2. 學習率 $(\eta)$：控制每次更新的幅度

    3. 更新公式： $
      \theta \leftarrow \theta - \eta \frac{\partial L}{\partial \theta}
      $

    4. 每次更新後都要重新計算梯度，因為損失函數會隨 $\theta$ 的變化而改變

    5. 重複直到收斂或驗證集表現停止提升 (例如，模型在驗證集的表現不再提升)

    • 範例：最小化 $L(\theta) = (\theta - 3)^2$

      • 導數為：$\frac{dL}{d\theta} = 2(\theta - 3)$

      • 初始值：$\theta = 0$，學習率：$\eta = 0.1$

        步驟 $\theta$ 梯度 更新後 $\theta$
        1 0 (-6) (0.6)
        2 0.6 (-4.8) (1.08)
        3 1.08 (-3.84) (1.464)

      若不重新計算梯度，會一直用舊的方向更新，導致無法準確收斂

      新的梯度由更新後的 $\theta$ 代入導數計算取得（例如，在步驟 2 中 $\frac{dL}{d\theta} =2(0.6−3)=−4.8）$

  • 方法二：隨機梯度下降 (Stochastic gradient descent):

    改善方法一 (GD) 可能會遇到的問題 (例如，計算成本高且慢)

    • 透過在每一步中，一次只選一組不一樣的小批量 (minibatch $B$) 資料去計算梯度，而不是全部資料

    • 一些你必須知道的基本概念

      • Batch size: 一小批量資料的大小，越大通常更新方向越好，但太大也會造成計算量過大

      • Iteration: SGD 每次使用一小批量資料計算梯度的過程稱為一次迭代 (Iteration 數量會等於 dataset size / batch size)

      • Epoch: 一次完整使用整個資料集計算一次

  • 其他常見的方法： Adam、Adagrad、Adadelta、RMSprop

神經網路？

一樣要處理最佳化問題，但是 $f(x)$ 更複雜

  • 如果要計算一個更複雜的函數，例如：$f(x) = W_2(W_1x)$, $\theta = {W_1, W_2}$？

    這時候我們就要用到反向傳播 (Backpropagation)，透過 chain rule 來計算梯度

    E.g. $\nabla_xf = \frac{\partial f}{\partial (W_1x)}\cdot \frac{\partial (W_1x)}{\partial x}$


    • 正向傳播用來計算損失函數（目前下降了多少），反向傳播用來計算梯度（下降最快的方向）

    • 圖中右邊的 $W_2$ 應該改為 $h$

  • 如果 $f(x)$ 引入非線性 (nonlinearity)？

    • Rectified linear unit (ReLU)：$f(x) = \max(0, x)$
    • Sigmoid $\sigma(x)$：$f(x) = \frac{1}{1+e^{-x}}$

    可以提高模型的表達能力，意味著可以學習更複雜的函數

    例如，在多層感知器 (Multi-layer Perceptron) 中，可以加入一個非線性層：

    $x^{(l+1)} = \sigma(W_lx^{(l)} + b^{(l)})$

    • $W_l$ 是第 $l$ 層的 weight matrix
    • $b_l$ 是第 $l$ 層的 bias vector
    • $x^{(l)}$ 是第 $l$ 層的輸出
