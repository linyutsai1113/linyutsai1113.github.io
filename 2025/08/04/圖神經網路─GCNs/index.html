圖神經網路 (GNNs) ─ 從節點嵌入 (Node Embedding) 到圖卷積網路 (GCN)

Created2025-08-04|Updated2025-08-04|學習筆記
|Post Views:

筆記內容來自 CS224W: Machine Learning with Graphs Stanford / Fall 2021

前言：節點嵌入 (Node Embedding) 的核心思想

在圖神經網路 (GNNs) 中，節點嵌入 (node embedding) 是一個核心概念，目的是將圖中每個節點轉換為一個低維空間中的向量表示，保留其在圖中的結構與屬性資訊。

當前所有主流的節點嵌入方法，其根本思想都可以歸結為鄰域聚合 (Neighborhood Aggregation)，也就是一個節點的表示，應該由其周圍的鄰居來定義。

實現這個思想的方式有所不同：

  • 像 DeepWalk、node2vec 等方法，透過在圖上進行隨機遊走 (random walk) 來採樣大量的「節點路徑」。模型會學習在這些路徑上共同出現的節點之間的關係，而非僅僅是直接相連的鄰居。

  • 而像 Graph Convolutional Networks (GCNs) 和 GraphSAGE 等現代 GNN 框架，則採用更直接的訊息傳遞 (Message Passing) 機制。它們設計了神經網路層，直接聚合鄰居節點的特徵，並透過端對端 (End-to-End) 的方式進行訓練，使模型能為特定任務學到最合適的節點嵌入。

    端對端 (End-to-End) 表示節點嵌入與圖任務不再分開訓練

這篇文章將主要聚焦於基於訊息傳遞的 Graph Convolutional Networks (GCNs) 模型。

圖的基本表示方式

假設我們有一個 graph $G$：

$V$ 是節點集合，$v$ 是 $V$ 中其中一個節點，$N(v)$ 是節點 $v$ 的鄰居所構成的集合

$A$ 是鄰接矩陣，假設是 binary

$X \in \mathbb{R}^{|V| \times m}$ 是節點特徵矩陣，例如： 在社交網路中的使用者檔案、文章、影像等等，或是生物網路中的基因表達、功能資訊等等，有時候節點的鄰居數量也會被作為特徵

如何建構 GNN：從鄰接矩陣與節點特徵開始

最簡單的方法：$X$ 和 $A$ 直接 join 在一起 ，然後用一個全連接層 (fully connected layer) 來處理。

  • 缺點：模型無法應用到不同大小的圖 (graph)、對節點的順序很敏感

那有沒有其他更好的方法，答案是有的。

Graph Convolutional Networks (GCNs)：一種典型的 GNN 架構

GCNs 借用了卷積神經網路 (CNNs) 中「滑動視窗」的概念，並將其概括應用於圖結構資料。然而，圖資料具有排列不變性 (permutation invariance) ，也就是節點的順序改變不會影響整體圖的結構與意義。因此，圖中的節點特徵缺乏固定的空間排列，不像影像或序列資料那樣擁有明確的鄰近關係與順序。

基於這一特性，圖上無法直接使用類似 CNNs 中固定大小的卷積核 (kernel) 進行滑動操作。取而代之的是，GCNs 採用基於鄰接關係的訊息聚合 (aggregation) 機制，從每個節點的鄰居中學習特徵表示。

Aggregation 機制與計算圖（Computation Graph）

在了解聚合之前必須要先知道什麼是計算圖 (computation graphs)，這是一種用來表示數學運算的有向無環圖 (DAG)，一個網路節點可以基於它的鄰居產生一個計算圖，每一個計算圖可以是任意深度，每一層都是在對節點做嵌入的動作，layer $0$ 的輸入是對應節點 $u$ 的鄰居節點特徵，layer $l$ 的輸入是 layer $l-1$ 的輸出。

當中的運算我們稱作聚合函數，通常會用平均 (average)、加總 (summation) 的方法，因為他們具有排列不變性，也就是說，無論鄰居節點的順序如何改變，聚合的結果都不會受到影響。

使用平均聚合方法應用到神經網路上：

$h^0_v = x_v$

$h^{(l+1)}_{v} = \sigma(W_l \sum_{u \in N(v)} \frac{h^{(l)}_u}{|N(v)|} + B_lh_v^{(l)}), \space \forall l \in { 0, \cdots,L-1}$

用矩陣表示的話： $H^{(k+1)} = \sigma(\tilde{A} H^{(k)}W^T_k + H^{(k)}B^T_k)$

where $\tilde{A} = D^{-1}A$

注意：並不是所有 GNNs 都可以用矩陣表示，有些聚合函數很複雜

Hint：

Let $H^{(l)} = [h_1^{(l)},\cdots,h_{|V|}^{(l)}]^T$

Then $\sum_{u \in N(v)} {h^{(l)}_{u}} = A_{v,:}H^{(l)}$

  • $A$ 是鄰接矩陣，$A_{v,:}$ 表示第 $v$ 行，是一個 row vector，表示節點 $v$ 的所有鄰居

Let $D$ be the diagonal matrix with $D_{(v,v)} = Deg(v) =|N(v)|$ then $D_{(v,v)}^{-1} = \frac{1}{|N(v)|}$

Therefore, $\sum_{u \in N(v)} \frac{h^{(k-1)}_u}{|N(v)|} \rightarrow H^{(k+1)} = D^{-1}A H^{(k)}$

$z_v = h^{(L)}_v$ 這就是最後的節點嵌入 (node embedding)

接著去訓練 parameters $W_l, B_l$

GNN 的訓練方式：Supervised vs Unsupervised

  • 在監督式學習 (supervised learning) 中，我們一樣可以用最小化損失函數來訓練 GNNs，像是 $\mathop{min}\limits_{\theta} L(y, f(z_v))$，其中 $y$ 是節點的標籤，$z_v$ 是節點 $v$ 的嵌入向量。

  • 在非監督式學習 (unsupervised learning) 中，因為沒有節點標籤，可以改用相似度去思考，通常相似的節點有著相似的嵌入：

    $L = \sum_{z_u,z_v} CE(y_{u,v}, \space DEC(z_u,z_v))$

    • $z_u,z_v$ 是兩個節點的嵌入向量
    • 當 $y_{u,v} = 1$ 時，表示 $z_u$ 和 $z_v$ 越相似（接近）
    • $CE$ 是 cross-entropy loss
    • $DEC$ 是一個解碼器，例如簡單的內積 (dot product)，可以用來判斷兩個節點是否相似，例如：兩個節點的嵌入向量之間的距離，或是兩個節點的鄰居之間的關係。
